# Learn With Mom Academy Standards

## Mission architecture
Every module follows: Brief → Learn → Explore → Practice → Explain → Real World → Finish.

## Content rules
- Every question must reveal understanding, guide a decision, or prepare a real conversation.
- Remove filler, trivia, and unanswered prompts that do not teach.
- Define a term before using it as a decision criterion.
- Translate percentages into meaningful dollars when cost is discussed.
- Explain time horizons using the date the money is needed, not adult jargon.
- Separate illustrations from promises.
- Prefer “you” and direct student language over third-person narration.

## Interaction rules
- One interaction should teach one idea.
- Give immediate explanatory feedback.
- Do not award completion for random clicking when a written explanation or correct assessment is required.
- Save progress locally, and state that limitation clearly.

## Visual rules
- Calm, premium, spacious, and consistent.
- Strong hierarchy, large readable type, clear buttons, and responsive layouts.
- Motion is subtle and respects reduced-motion preferences.
- Color never carries meaning alone.

## Assessment rules
- Test reasoning, not obscure vocabulary.
- Written explanation and real-world application are part of mastery.
- Parent guidance focuses on questions and misconceptions, not scripts that replace the student's thinking.

## V6 Product Standard

Every finished module should aim for roughly 40% reading and 60% doing. Interaction must require prediction, comparison, explanation, experimentation, research, or judgment. Decorative clicking does not count.

Every major concept should include a visual model before or alongside prose. Every module should include at least one decision simulation, one teach-back prompt, one real-world investigation, and one notebook opportunity.

Achievements recognize habits and demonstrated thinking: patience, investigation, explanation, evidence, and reflection. They should not reward random page visits alone.

## Mascot standard
Milo the wise cat appears only when he improves clarity, calm, or continuity. He is not childish comic relief. His voice is brief, evidence-first, curious, and never predicts markets with certainty.

## Prediction standard
Interactive market cases require the learner to predict before seeing the explanation. Feedback rewards the reasoning chain rather than pretending uncertain markets always have one guaranteed outcome.
