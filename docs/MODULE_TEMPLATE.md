# Reusable Module Template

1. Mission Brief: outcome, why it matters, three objectives.
2. Learn: direct instruction and one concept-building interaction.
3. Explore: cause-and-effect or comparison activity.
4. Practice: decision lab with contextual feedback.
5. Explain: teach-back and misconception correction.
6. Real World: observable task using an actual tool, document, place, or conversation.
7. Finish: short mastery check, badge, certificate, and parent readiness notes.
